Bonjour Gemini ! Je démarre mon émulateur Amstrad CPC en Rust à partir d'un projet vierge. Je souhaite que nous codions de manière très modulaire, un composant par fichier, comme décrit dans mon fichier ARCHITECTURE.md ci-joint.

Notre premier objectif est de poser les fondations pour faire tourner la ROM de diagnostic de Noël Llopis (llopis/amstrad-diagnostics), qui fait 16 Ko, sur notre carte mère.

Pour ce faire, nous allons utiliser mon cœur Z80 qui est importé via mon Cargo.toml (depuis la branche `cpc` du dépôt https://github.com/nicolasbauw/ZilogZ80).

Pour cette première étape, peux-tu :
1. M'expliquer brièvement de quoi mon CPU (ZilogZ80) a besoin au minimum de la part de notre structure de Bus pour lire et écrire (mémoire et I/O).
2. Me générer le code de base pour `src/memory.rs` (qui contiendra nos 64 Ko de RAM et un espace pour stocker la ROM de test).
3. Me générer le code pour `src/bus.rs` qui contiendra notre structure `CpcBus` et implémentera le Trait requis par mon CPU Z80 pour lier tout ça.
4. Et génère-moi également un `src/main.rs` minimaliste qui charge le fichier de la ROM de diagnostic (qui se trouve dans bin/), initialise le Bus et le CPU, et lance la boucle d'exécution de base.

Nous allons utiliser la fonction execute() instruction par instruction pour synchroniser le Bus et les composants via un système de ticks.
Donne-moi les instructions de création de fichiers étape par étape, j'utiliserai l'assistant en ligne de Zed pour les remplir !
